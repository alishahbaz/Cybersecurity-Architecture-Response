## Main Idea

Security is not just about stopping attacks.

A complete security posture includes:

```text
Prevention + Detection + Response = Security
```

This Wiki is mainly about the **Response** part.

---

## Why Response Matters

Even if prevention and detection are strong, a breach can still happen.

If an attacker is present in the environment:
- The sooner you detect it, the better.
- The sooner you contain it, the better.
- The more repeatable your response is, the faster you recover.

That is why modern organizations use:
- **Incident Response (IR)**
- **SOAR**
- **Playbooks**
- **Automation and orchestration**
